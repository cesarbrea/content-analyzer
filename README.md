This application takes a product description and turns it into a creative brief.
Then it ingests images or videos -- creative assets, more generally.
It looks at the images / frames (and eventually audio) and suggests tags.
Then it compares what it "sees" with the creative brief to suggest degree of alignment on several dimensions.
Finally it suggests fixes to the creative assets for better alignment.
The application can be used as a "muse" for creative teams to tune their work.
Or, it can provide enriched tagging so that the relationship between creative attributes and creative performance can be better understood.
This allows building better customer response propensity models and better media mix models (by introducing creative features).
